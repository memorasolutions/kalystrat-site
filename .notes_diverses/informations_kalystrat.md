### Domaines - Importance et priorite

#### Essentiels (a conserver absolument)

| Domaine | Raison | Expiration |
|---------|--------|------------|
| **kalystrat.ca** | Domaine principal, site actif, courriels dessus | 2029-03-02 |
| **kalystrat.com** | Protection de marque, extension internationale. Tout concurrent ou squatteur pourrait le prendre si abandonne | 2027-02-15 |

- **kalystrat.ca** : c'est le coeur de tout. Site web, courriels (6 adresses @kalystrat.ca), identite de marque. Bien enregistre jusqu'en 2029, c'est le seul domaine enregistre pour 3 ans - signe qu'ils l'ont identifie comme le principal.
- **kalystrat.com** : meme si le .ca est le domaine principal (correct pour une entreprise canadienne), le .com est le reflexe mondial. Ne pas le renouveler serait risque - quelqu'un pourrait le prendre et creer de la confusion.

#### Utiles selon la strategie (a evaluer)

| Domaine | Raison | Expiration |
|---------|--------|------------|
| **kalystratcapital.ca** | Sous-marque ou division? Protege le nom "Kalystrat Capital" | 2027-03-02 |
| **groupekalystrat.ca** | Sous-marque ou division? Protege le nom "Groupe Kalystrat" | 2027-03-02 |

- **kalystratcapital.ca** : utile si Kalystrat a une division "capital" / investissement. Sinon, c'est une protection defensive a CA$36/an - pas cher pour empecher un tiers de l'utiliser. A discuter avec le client.
- **groupekalystrat.ca** : meme logique. Si Kalystrat evolue en groupe d'entreprises, ce domaine sera precieux. Sinon, protection defensive abordable.

#### Recommandation

1. **Garder les 4 domaines** - a CA$36/an chacun, le cout total est modeste (CA$144/an) pour une protection de marque complete
2. **Rediriger** kalystrat.com, kalystratcapital.ca et groupekalystrat.ca vers kalystrat.ca (redirection 301)
3. **Considerer transferer les domaines** vers un registraire plus specialise (ex: Cloudflare Domains, Porkbun) pour centraliser la gestion et potentiellement reduire les couts. Squarespace est un bon outil pour les sites, mais pas le meilleur registraire
4. **Resilier le plan Squarespace Basic** (CA$252/an) si le site n'est plus utilise la-bas - c'est le plus gros poste d'economie potentiel
5. **Verifier que les auto-renouvellements sont actifs** sur tous les domaines pour eviter une perte accidentelle
